# plain Spectre frequency sweep v12 2syn_2tail patch9

This patch is based on the existing `plain_spectre_frequency_sweep_reorg_v12_2syn_2tail_patch8.tar.gz` flow and changes only the preparation script behavior needed for the next run.

## Change

`import_template.sh`, generated by `experiments/frequency_sweep/bin/spectre_sweep_plain_reorg_v12_2syn_2tail.sh prep`, now forces the Spectre transient analysis to:

```spectre
tran tran stop=0.1s
```

The two-voltage/two-current output remains unchanged:

```text
iout_172 iout_56 vpre vpre1
```

`strobeperiod` is still removed, so the export remains full adaptive-output data over the shorter 0.1 s simulation window.

## Install

From the repository root:

```bash
cd /home/s5117909/Documents/thesis/thesis_codebase
tar -xzf plain_spectre_frequency_sweep_reorg_v12_2syn_2tail_patch9_0p1s.tar.gz
```

## Fresh run

```bash
NUM_JOBS=4 RUN_LABEL=2syn_2tail_plain \
./experiments/frequency_sweep/bin/spectre_sweep_plain_reorg_v12_2syn_2tail.sh prep

cd database/<new_run_id>
./import_template.sh
grep -n "tran tran" netlist_template/raw/input.scs
./refresh_spectre_runtime.sh
source ./setup_spectre_env.sh && check_spectre_runtime && check_export_runtime
./run_all_workers.sh
```

The grep should show `stop=0.1s`.
